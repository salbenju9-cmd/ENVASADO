Las asociaciones REF REAL–cliente–referencias proceden del Excel importado. El operario puede localizar una referencia escribiendo parte de cualquier columna.

Columnas esperadas del Excel
Texto adicional 3 → Cliente · Texto adicional 4 → Referencia cliente · REF REAL → REF REAL · CODIGO SAP → Código SAP · DENOMINACION SAP → Referencia/denominación SAP.
Se importan las filas de envasado donde aparezca SACO o BIGBAG. Para SILOS se leen RP y FV2000 secos con S para cuarzo, FC para molturado aunque no contenga S, y el resto de FV secos con S para feldespato en grano. Siempre se excluyen SACO y BIGBAG. Para ACOPIOS se leen RP húmedos con H y FV2000H como cuarzo; el resto de FV húmedos con H como feldespato. Se excluyen SACO, BIGBAG y FC.

ACTUALIZAR STOCK CON CARGAS DE CARGADOS.XLSX
Se procesan únicamente las expediciones posteriores a la fecha y hora de referencia. SACO resta palets, BIGBAG resta Big Bags y FC sin envase resta toneladas de los silos de molturado. Las unidades de SACO y BIGBAG se calculan a partir del peso neto y del peso teórico configurado. Si la carga calculada supera el stock disponible, el programa pregunta antes de continuar; si autorizas, descuenta solo lo disponible y deja el stock exactamente en 0, nunca en negativo.
FECHA Y HORA QUE SE LEEN DE CARGADOS.XLSX
Fecha de carga: columna Fe.act.desp.exped.
Hora de carga: columna Hora act.inic.carga
El programa combina exclusivamente estas dos columnas. Si la fecha o la hora están vacías o no son válidas, la carga no se aplica y se muestra una incidencia. Nunca se sustituye una hora ausente por 00:00:00.
Selecciona primero la carpeta de trabajo.
IMPORTAR PRODUCCIÓN DESDE STOCK_ENVASADO_2026.XLSM
Se leen las filas de la hoja que contiene las columnas Presentación, REF REAL, Número, Total y Silo. El programa guarda la fecha/hora del último movimiento importado y, además, recuerda cada fila ya procesada para impedir duplicados.
REGLAS DE IMPORTACIÓN
SACO / BIGBAG: se añaden al STOCK las unidades indicadas en la columna Número.
MOLIENDA: se añaden al silo de MOLTURADO indicado en Silo las toneladas de la columna Total.
EXCEPCIÓN FC100 GRANEL DESCLASIFICADOS: si el silo indicado tiene asignada esa referencia, admite cualquier referencia de molienda. Las toneladas se suman al silo y pasan a contabilizarse como FC100 GRANEL DESCLASIFICADOS; en HISTÓRICO queda anotada la referencia original y la conversión.
RESTA DESDE SILO CON REFERENCIA DISTINTA: si un BIGBAG FC indica consumir de un silo cuya referencia no coincide, el programa preguntará antes. Si se autoriza, resta del silo, no cambia su referencia y continúa la importación.
BIGBAG con referencia FC: además de sumar los Big Bags al STOCK, se restan del silo de MOLTURADO indicado en Silo las toneladas de Total.
El silo 1 corresponde a M1, el 2 a M2, etc. El programa nunca deja un silo en negativo: si faltan toneladas, pregunta antes de dejarlo a 0.
Funciona igual que en IMPORTAR CARGADOS: puedes consultar o modificar manualmente la fecha/hora de referencia. Solo se procesan movimientos desde esta referencia en adelante y el control individual de filas evita duplicados. Después de importar, se actualiza automáticamente con la fecha/hora del último movimiento procesado.
Selecciona primero la carpeta de trabajo.
